# Лабораторная работа 1 (вариант 5)

## Установка
```bash
pip install -r requirements.txt
```

## Запуск
Открыть нужный файл в VS Code и нажать `F5` (Run Python File),
либо в терминале:
```bash
python task1.py
python task2.py
python task3.py
python task4.py
python task5.py
```

- `task1_foo.png`, `task1_foo_correct.png` — графики к заданию 1
- `task2_comparison.png` — сравнение алгоритмов задания 2
